## نکات باقی‌مانده (غیرمسدودکننده)

- تست‌های e2e (`npm run test:e2e`) PostgreSQL توکار خودکار بالا می‌آورند، ولی
  اولین `prisma generate`/`db push` نیاز به دانلود engine از
  `binaries.prisma.sh` دارد — روی سیستم خودت (اینترنت عادی) مشکلی نیست.
- پوشش تست واحد روی زیرساخت (guard، filter، rate-limit، pagination) خوب است؛
  ماژول‌های بیزینسی بیشتر به e2e تکیه دارند.
- `SWAGGER_ENABLED=true` پیش‌فرض dev است — در production خاموش شود (در
  `.env.example` هشدار داده شده).

## اتصال فرانت (قدم بعدی)

- فرانت `NEXT_PUBLIC_API_URL` را از env می‌خواند و اعتبارسنجی می‌کند که `/api/v1` داشته باشد.
- `CORS_ORIGINS` بک‌اند به‌طور پیش‌فرض `localhost:5173` و `localhost:3001` را مجاز می‌کند.
- در dev، mock کاتالوگ با `NEXT_PUBLIC_API_MOCKING=enabled` فعال می‌شود؛ برای
  API واقعی خاموشش کن.
- همهٔ پول‌ها Integer تومان (IRT) هستند — در فرانت فقط نمایش، نه محاسبه.
